# Generated data

Everything in this directory is produced by one command from the
re-implementation of the 2003 model. Nothing here was extracted from the
original paper, whose results sections were not part of the source material.

```bash
node engine/generate.mjs
```

Canonical run: **2,500 simulated days, seed 20030601**, at the Table 2.1
parameter values plus the three illustrative values the table does not publish
(τ = 3 days, r = R, population floor 10%). Both are set at the top of
`engine/generate.mjs`; changing either changes every published figure.

| File | Contents |
|---|---|
| `run.json` | `price`, `fundamental`, `volume`, `ret`, `opinion`, `share`, one entry per simulated day |
| `derived.json` | `acfAbsRet`, `acfVolume`, `acfRet`, `hist`, `scatter`, `fit`, `clusters`, `stats` |
| `microstructure.json` | `events` — 400 consecutive events with their arrival times, from a separate run at seed 4242; `race` — the ten jump rates of one settled market state |

Every file carries a `provenance` block naming the seed, the run length, the
event count and the command that produced it.

`site/data/*.js` holds the same three payloads assigned to globals, which is the
form the page loads so that it also works from a `file://` origin. They are
regenerated by the same command and should never be edited by hand.

Measurement definitions — in particular what is counted as volume — are in the
project README under "Measurement definitions".
